## 单文件格式

```markdown
# ADR-NNN | 标题

- 日期：YYYY-MM-DD
- 状态：提案中 / 实施中 / 已完成 / 已废弃

## 需求

用户要什么（原话或确认措辞），含子需求拆分

## 进度状态

各子需求当前状态 + 剩余待办（表格）

## 最终产物

交付资产清单：路径 + 一句话（表格）

## 是否满足需求

判定（满足/部分/不满足）+ 证据（验证方式、用户确认）
```

## 维护规则

- 序号递增，不重排不删除；被取代标"已废弃"并注明替代者
- 需求推进只改"进度状态"节；交付补"最终产物"节；验证后改"是否满足需求"节并同步索引
- 联动：需求落地为 rules/skills/CLAUDE.md 改动时，在"最终产物"节列明路径
